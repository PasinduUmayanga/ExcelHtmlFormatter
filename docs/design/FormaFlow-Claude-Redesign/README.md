# FormaFlow Claude-ready redesign package

Contains a complete Claude Code implementation specification and six PNG image references (original app + five redesigned concepts).

## Get started

1. Place the `FormaFlow-Claude-Redesign` folder inside your project's `docs/design/` directory.
2. Open Claude Code in the existing FormaFlow repository.
3. Tell Claude: “Read `docs/design/FormaFlow-Claude-Redesign/CLAUDE_IMPLEMENTATION_GUIDE.md` and all referenced images. Audit the project first, show a plan, then implement in phases while preserving existing functionality.”

## Files

- `CLAUDE_IMPLEMENTATION_GUIDE.md` — design system, pixel-fidelity targets, screen-by-screen behavior, atomic architecture, validation, verification, implementation roadmap, quality gates and paste-ready prompt.
- `references/00-original-current.png` — original screen.
- `references/01-home-action-selection.png` — primary Home design.
- `references/02-home-recent-files.png` — Home table/detail alternative.
- `references/03-upload-guided-workspace.png` — primary Upload screen.
- `references/04-upload-summary-alternate.png` — upload alternate.
- `references/05-complete-screen-blueprint.png` — all major workflow screens.

The PNG references are visual guides, not component code or assertions of currently supported features.
