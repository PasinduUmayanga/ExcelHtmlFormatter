# Getting started

Format your first workbook in five steps, and find your way around.

FormaFlow turns HTML tags inside Excel cells into real formatting. A cell containing `<b>my name</b> is <i>pasindu</i>` becomes **my name** is _pasindu_ in a new workbook. Your original file is never changed.

## Your first formatted file

1. On **Home**, **Excel** and **Format HTML tags** are already chosen: click **Continue**. On the Open screen, drop an `.xlsx` workbook or click to browse for one.
2. **Select sheets.** Sheets that contain HTML are ticked for you. Click **Analyse tags →**.
3. **Tag analysis** shows each tag that was found and how it will look. Tags marked **No style** need a style, or their text is left plain.
4. Click **Preview result →**. FormaFlow checks that no text is lost, then shows the cells as they will look.
5. Click **Save formatted file…** and choose a name. FormaFlow reads the new file back to check it, then takes you back to **Home**, which shows what was saved.

## What you need

- An Excel workbook in `.xlsx` format. Older `.xls` files and password-protected workbooks can't be opened: save them as `.xlsx` in Excel first.
- Cells whose text contains HTML tags, such as `<b>`, `<i>`, `<br>` or `<ul><li>`.

## Finding your way around

- **Home** is where you choose the kind of file and what to do with it, continue with the file you have open, and see your recent activity.
- The sidebar shows the four steps. They are locked until you start from Home (**Continue**, or **Open** next to a recent file), then each step becomes available once the step before it is done. After a save they lock again until you start the next file.
- **Formatting Profiles** in the sidebar opens **Tag styles**, which sets how each tag looks. Your styles are kept for every file.
- **Theme** at the top switches between Light, Dark and System.
- **Help** at the top (or **Help & Support** in the sidebar) brings you back here. The path at the top left shows where you are. Use the search box to find any topic.
